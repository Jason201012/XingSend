FAQ

常见问题
Frequently asked questions
XingSend 和 LocalSend 是什么关系？ What is the relationship between XingSend and LocalSend?

XingSend 是基于开源项目 LocalSend（Apache-2.0）的个人定制版：更换了名称与图标、独立了应用包名，方便与官方版并存。核心传输协议完全一致。

XingSend is a personal build of the open-source project LocalSend (Apache-2.0) with its own name, icon and app identity. The transfer protocol is identical.

能和官方 LocalSend 互传文件吗？ Can I transfer files with official LocalSend users?

可以。协议完全兼容，同一局域网内 XingSend 与官方 LocalSend 可以互相发现并互传文件。

Yes. The protocol is fully compatible — XingSend and official LocalSend devices can discover and send to each other on the same network.

需要连接互联网吗？ Does it need an internet connection?

不需要。传输完全在本地局域网内完成；两台设备连同一个 Wi-Fi（或热点）即可。

No. Transfers happen entirely over your local network — just connect both devices to the same Wi-Fi or hotspot.

支持哪些平台？ Which platforms are supported?

本仓库提供 Windows（安装程序 / 便携版）与 Android 安装包。由于协议互通，其他平台的设备仍可使用官方 LocalSend 与 XingSend 互传。

This repository provides Windows (installer / portable) and Android packages. Thanks to protocol compatibility, other platforms can still use official LocalSend to talk to XingSend.

如何升级到新版本？ How do I upgrade?

安卓：直接下载新版 APK 覆盖安装（签名一致，数据保留）；Windows：运行新版安装程序覆盖安装即可。

Android: install the new APK over the old one (same signature, data preserved). Windows: run the new installer over the old install.
